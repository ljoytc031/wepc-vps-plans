## 4837 和 9929、双 ISP 和原生 IP，差别在哪

4837 是联通 AS4837，国内三网回程走联通出口，属于优化线路里的基础档。9929 是联通精品网，国际出口优先级更高，晚高峰表现更稳。美国款从 12.90 澳元升到 15.90 澳元，多出来的 3 澳元买的就是这段回程。

双 ISP 指 IP 的注册信息分属两个运营商。平台判断一条 IP 是不是机房 IP，看的是注册信息和历史行为，双 ISP 能降低被直接标记的概率。原生 IP 指 IP 注册地和机房实际位置一致，没被划进数据中心段。TikTok 对 IP 归属地敏感，这是 WePC 整条产品线的卖点，也是它配置低还能卖到这个价的原因。

台湾款的上游是 Akari Networks，机房在台北，今年 3 月的一篇第三方测评实测能解锁 TikTok、ChatGPT、Claude、Gemini、Netflix 和台区流媒体，Geekbench 6 单核 512 分，跑一般任务够用。官方提示三网建议走中转，实测移动可以直连。

## 1.5TB 是双向计费，超流量只限速

美国款标 1.5TB，英国原生家宽写的是“1.5 TB 双向流量”。WePC 的套餐普遍按 In+Out 计费，1.5TB 双向意味着上行加下行合计 1.5TB，**单向可用大约只有 750GB**。这一点在官网页面上的表述并不统一，美国页只写“1.5 TB”，英国页才写明“双向”。

750GB 能撑多久直播？按 1080p 推流 4Mbps 估算，一小时约 1.8GB，750GB 大约 415 小时，摊到每天 8 小时能用近两个月。只发短视频、做账号运营，这个量很宽裕；24 小时不间断推流，半个月就见底。

超流量不会停机。美国款限速到 3Mbps，英国 TikTok 专用限速到 5Mbps，不额外扣费。3Mbps 大约 375KB/s，跑 480p 直播勉强，1080p 推流会直接卡住。好处是业务不会突然中断，坏处是限速之后基本只能维持最低限度的在线。
